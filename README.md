# Career-Ops & Application Assistant

A streamlined workspace for candidate profile management, resume tailoring, and targeted job applications.

---

## Workspace Structure

- **my-resume/**: Master LaTeX resume source files (Awesome-CV format), fonts, and modular section files.
- **data/**: Canonical profile definitions (canonical_profile.json and canonical_profile.md).
- **job_research/**: Role-fit analyses, targeting guidelines, and market research.
- **scripts/**: Automation scripts and utilities.
- **.env**: Local environment variables and credentials (ignored by git).
